# 🌙 İSG ROTA

DSP (Diğer Sağlık Personeli) belgesine hazırlananlar için topluluk destekli, açık kaynaklı sınav hazırlık uygulaması.

---

## 📱 Özellikler

- **Deneme Sınavı** — 50 soruluk karışık deneme sınavı
- **Soru Havuzu** — Tüm sorularla sınırsız pratik
- **Soru Ekle** — PDF veya kamera ile soru ekleyerek topluluğa katkı sağla
- **Soru Oyla** — Eklenen soruları oylayarak havuzun kalitesini artır
- **Hatalı Bildir** — Yanlış soruları işaretle
- **Otomatik Güncelleme** — Sorular sunucudan otomatik güncellenir, internet yoksa son sürüm çalışır
- **Karanlık / Aydınlık Tema** — Sistem temasını takip eder veya manuel seçim yapılabilir
- **Günlük Hatırlatıcı** — Her gün saat 20:00'de çalışma bildirimi

---

## 🔒 Gizlilik

Bu uygulama **hiçbir kişisel veri toplamaz.**

- Kimliğine hiçbir şekilde ulaşılamaz

---

## 🛠️ Kurulum (Geliştirici)

1. Repoyu klonla:
```bash
git clone https://github.com/gecelimani/isg-rota.git
```

2. `local.properties` dosyasına API key ekle:
```
API_KEY=senin_api_keyin
```

3. Android Studio ile aç ve çalıştır.
